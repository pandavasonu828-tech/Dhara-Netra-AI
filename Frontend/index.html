Evaluation Metrics Lab

Statistical evaluation is separated from runtime confidence. Use manually verified ground-truth data for defensible results.

Metrics implemented: CER, WER, Field Exact Match, Precision, Recall, F1, Completeness, Mismatch Rate and ECE calculation support. The prototype never presents invented accuracy numbers as measured results.

Classification metrics

Enter TP, FP and FN from a labeled evaluation set (for example, duplicate detection).

OCR / extraction metrics

One ground-truth field per line and the corresponding prediction on the same line number.

Process a document first to calculate runtime metrics from the actual extracted information. No sample/default values are inserted.
Enter verified evaluation data to calculate CER/WER, Precision/Recall/F1 or ECE.

Confidence calibration — ECE

Enter confidence values as decimals or percentages converted to decimals, and the corresponding ground-truth correctness labels (1 = correct, 0 = incorrect).

How confidence is interpreted

The field-level confidence score is a prototype review-priority score. It combines OCR evidence, rule validation and cross-source comparison. It is not a legal authenticity probability. Production deployment should calibrate confidence against labeled ground truth, for example with Expected Calibration Error (ECE).

Duplicate Detection

Check whether a newly uploaded document is an exact duplicate or resembles an already registered document.

Detection layers: exact SHA-256 file match first, then structured-field signature comparison. Similarity is a review signal, not a legal conclusion.
